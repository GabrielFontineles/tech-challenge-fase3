# Predição e Inteligência Analítica para Alfabetização no Brasil

## Contexto do Problema

Continuação do Tech Challenge Fase 2, onde construímos uma pipeline híbrida de dados
para análise do Indicador Criança Alfabetizada. Nesta fase, utilizamos os dados da
camada Gold para desenvolver modelos preditivos e análises estratégicas.

## Objetivo Analítico

Desenvolver um modelo supervisionado capaz de prever se um município será
considerado alfabetizado ou não, utilizando variáveis educacionais, territoriais
e socioeconômicas.
